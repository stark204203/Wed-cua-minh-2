Cách thêm anime của bạn

Chỉ cần sửa danh sách dữ liệu trong tệp index.html.

1

Mở tệp trên GitHub

Vào repository của bạn, mở index.html rồi nhấn biểu tượng bút chì để chỉnh sửa.

2

Thêm thông tin anime

Tìm dòng const animeList = []; trong phần JavaScript ở gần cuối tệp. Thêm dữ liệu anime vào giữa hai dấu ngoặc vuông.

3

Lưu và cập nhật

Nhấn Commit changes. Chờ GitHub Pages cập nhật rồi tải lại website. Anime mới sẽ xuất hiện trong thư viện.
